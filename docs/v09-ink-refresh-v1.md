Declared 2026-10-18 before new profile/performance measurements.

The user requests cheaper forecasts without changing strategy or safeguards,
so more comparisons finish within36 ms. The budget100 diagnostic establishes
compute sensitivity; it does not establish the hottest current method.

First profile the retained exact batched36 submission on all524 observed
states/both seats from games907134258,907134581,907134651,907134720. Replay

The proposed single optimization is selective connection refresh after a
hypothetical ink operation. Deleting cells cannot create a connection or make
an unaffected canonical shortest path noncanonical. Recompute only paths

buffers. All rules remain in core. Keep complete ink effects, terminal checks,
target ordering, route candidates, RNG, evaluation, depth/width and timers.

the comparison base keeps batchingON, NOISE0.1 and missed-deadlineOFF. Default
36 ms, batchingOFF, selectedv09 and all earlier verdicts remain unchanged.

Before timing, verify differential core tests for both refresh modes, path and
income equality, ink/copy/reset cases, town/neutral ties, no-path states and
game-end guards. Run focused rollout/submission tests and `cgValidate` because
