# Rules inferred from Silver replays (not from a statement)

Source: 107 Silver-league games of the top 15 (2026-09-13), replayed through `btk.core` by
`gradlew cgValidate`. Status: **107/107 games reproduced exactly** (every placement, ink event,
per-turn score, connection path, game-end turn and final score). Replace with the official text
of `docs/rules/bronze.md` etc. once available; keep this file as the record of what was verified.

## DISRUPT

- Syntax: `DISRUPT <regionId>` or `DISRUPT <x> <y>` (the cell's region). Both are used by top bots.
- Costs no paint; combines freely with 3 paint points of `PLACE_TRACKS` in the same turn.
- At most one per turn (nobody ever sends two; treated as invalid locally).
- Never targets a region containing a town (0 cases in ~11 600 disrupts; treated as invalid locally).
- Effect: region instability +1. Both players' disrupts add up (2+2, 3+1 observed).

## Ink

- When a region's instability reaches **4** it is inked at the end of that turn's disrupt phase
  (before connections/scoring). 43 cases reached 5 when both players hit 3 -> 5 in one turn.
- Inking removes **all tracks** in the region (any owner) — viewer event `5` lists exactly the
  cells that had tracks.
- Inked regions stay inked for the rest of the game (no region is inked twice; no track is ever
  placed on an inked cell afterwards). Inked cells are impassable for new paths.
- Protocol: per-cell `instability` = region instability, `inked` = 1 for cells of inked regions.

## Turn order (as reconstructed)

1. Both command lines expanded; `PLACE_TRACKS` applied simultaneously (same cell -> neutral owner 2).
2. Disrupts applied; regions with instability >= 4 inked (tracks removed).
3. Active connections recomputed (shortest path, N/E/S/W tie-break from the requesting town).
4. Scoring: +1 per owned track per active connection to each player.

## Game end

- Hard limit 100 turns (10/107 games).
- Otherwise the game ends at the end of the turn after which **no desired pair can be connected
  through non-inked cells any more** (flood fill ignoring tracks). Verified on 97/97 early-ending
  games. Typical length 31-75 turns; about half of all regions are inked by then.

## Confirmed by the Bronze statement and the referee source (2026-09-13)

Statement: `docs/rules/bronze.md`. Source: https://github.com/CGjupoulton/SummerChallenge2026
(`Game.java`, `CommandManager.java`, `ActionType.java`, `TrainBFS.java`). Bronze is the **final
league rules-wise** (`level3/welcome_en.html`: "You have reached the final league"); Wood 1/2 were
tutorial objectives (`TutorialManager`). Everything above holds. Additional facts from the source:

- `INSTABILITY_THRESHOLD_BASE = 4`, `INSTABILITY_THRESHOLD_INCREASE = 0` (threshold never grows).
- Turn: `doIncome` (3 paint, 1 disruption point) → `computeAutobuilds` → `doActions` (all placements
  of player 0 in order, then player 1; same cell by both → neutral; then disrupts) →
  `doInstabilityCheck` (ink) → `moveTrains` (BFS per desired pair + scoring) → game-over check.
- **Impossible actions are skipped, not fatal**: out of grid, town cell, inked region, existing
  track (incl. own earlier placement this turn), not enough paint, second DISRUPT ("Not enough
  disruption points"), invalid/inked/town region, second AUTOPLACE. A failed action generated by
  AUTOPLACE cancels the remaining generated ones. Only a command matching none of the regexes
  (or an empty line) disqualifies (`InvalidInputException` → score −1). `btk.core.Rules.expand`
  implements exactly this (`PlayerMoves.skipped` vs `error`).
- Command regexes (case-insensitive, whole command): `AUTOPLACE x1 y1 x2 y2`, `PLACE_TRACKS x y`,
  `DISRUPT id`, `DISRUPT x y`, `MESSAGE [^;]*`, `WAIT`. Commands split on `;`, trimmed.
- Path BFS (`TrainBFS`): plain BFS from the requesting town over cells with a track (any owner)
  or a town; neighbours sorted by direction, first found path wins — our N/E/S/W descent
  reproduces it (107/107).
- POIs exist in the code (`TYPE_POI`, cost ×3) but `GridMaker` never creates them → no POIs in
  this contest. `CAN_BUY` and other purchase flags are dead code.
- Timing: `setTurnMaxTime(50)`, `setFirstTurnMaxTime(1000)`, `setMaxTurns(400)` (engine frames;
  the game's own `MAX_TURNS = 100`).
- `GridMaker` is the real map generator (java.util.Random seeded by `refereeInput` seed) — can be
  ported 1:1 to get authentic maps and reproduce any CG game's map from its seed.
